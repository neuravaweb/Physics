Equivalent Resistance Combinations

Explore the four unique equivalent resistances you can create using exactly three 1Ω resistors. Use the controls at the bottom to animate each configuration step-by-step.

1. All Series

Calculation:

Req = R1 + R2 + R3
Req = 1Ω + 1Ω + 1Ω
Req = 3Ω

2. All Parallel

Calculation:

1/Req = 1/R1 + 1/R2 + 1/R3
1/Req = 1/1 + 1/1 + 1/1 = 3Ω-1
Req = 1/3Ω ≈ 0.33Ω

3. Two Parallel, One Series

Calculation:

Rp = (1/1 + 1/1)-1 = 0.5Ω
Req = Rp + Rseries = 0.5 + 1
Req = 1.5Ω

4. Two Series, One Parallel

Calculation:

Rs = 1 + 1 = 2Ω
Req = (1/Rs + 1/Rp)-1 = (1/2 + 1/1)-1
Req = 2/3Ω ≈ 0.67Ω
