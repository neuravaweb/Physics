Section 7 · Problem 3

Resistance from Ohm's law.

PROPAGATION OF ERROR III
V = (10.0 ± 0.2) V · I = (2.00 ± 0.05) A
R = V / I

A division behaves like a multiplication for error propagation — relative uncertainties combine in quadrature. The current has a slightly larger fractional uncertainty (2.5 %) than the voltage (2.0 %), so it dominates the result.

Step 01 — Read the meters

Voltage and current.

V = 10.0 V, ΔV = ± 0.2 V (2.0 %)
I = 2.00 A, ΔI = ± 0.05 A (2.5 %)
Step 02 — Central value

Ohm's law.

R = V / I = 10.0 / 2.00
R = 5.00 Ω
Step 03 — Quadrature sum

Division: same rule as multiplication.

(ΔR/R)² = (ΔV/V)² + (ΔI/I)²
= (0.020)² + (0.025)²
= 4.00e-4 + 6.25e-4 = 1.025e-3
ΔR/R = 0.0320 → 3.20 %
ΔR = 0.0320 × 5.00 = 0.160 Ω
Reported value
R = 5.00 ± 0.16 Ω
