Series vs Parallel Circuits

Observe how resistance affects total current flow. Particle speed is proportional to current.

Series Circuit

Req = R1 + R2 + R3
Req = 15Ω + 30Ω + 50Ω
Req = 95Ω
I = V / Req
I = 12V / 95Ω
I ≈ 0.126 A

Parallel Circuit

1/Req = 1/R1 + 1/R2 + 1/R3
1/Req = 1/15 + 1/30 + 1/50
1/Req = 10/150 + 5/150 + 3/150 = 18/150
Req = 150 / 18 ≈ 8.33Ω
Itotal = V / Req
Itotal = 12V / 8.33Ω
Itotal ≈ 1.44 A
(I₁=0.8A, I₂=0.4A, I₃=0.24A)
