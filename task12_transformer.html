PROBLEM

Step-Down Transformer

Primary N₁ = 1000 turns. Secondary N₂ = 200 turns. Primary voltage V₁ = 120 V AC. Find V₂. Then with I₂ = 3 A, find I₁.

VOLTAGE RATIO

The same flux Φ links both coils. Each turn sees the same dΦ/dt, so voltage scales with turn count:

V₂ / V₁ = N₂ / N₁
V₂ = V₁ · (N₂ / N₁) = 120 · (200 / 1000) = 120 · 0.2 = 24 V
CURRENT RATIO

Energy is conserved (ideal transformer): P₁ = P₂. So V₁·I₁ = V₂·I₂, which inverts the turns ratio for current:

I₁ / I₂ = N₂ / N₁
I₁ = I₂ · (N₂ / N₁) = 3 · (200 / 1000) = 3 · 0.2 = 0.6 A

Voltage stepped down by 5×; current stepped up by 5×. Power balanced.

RESULT

POWER CHECK
P₁ = V₁·I₁ = 120 · 0.6 = 72 W P₂ = V₂·I₂ = 24 · 3 = 72 W P₁ ≡ P₂ ✓

Real transformers lose a few percent to core losses (hysteresis, eddy currents) and copper resistance — but the ideal-transformer math is the right starting point.
