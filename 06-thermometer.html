Section 7 · Problem 6

The last digit is half a degree of doubt.

INSTRUMENT PRECISION
reading = 25.4 °C
rule: ± ½ × LSB

A digital instrument can only display so many digits. The convention is that the absolute uncertainty equals half the resolution of the smallest displayed digit — anything more precise the device simply rounded away.

Step 01 — Read the display

What does the screen show?

T = 25.4 °C
smallest digit displayed: 0.1 °C
Step 02 — Apply the convention

Half of the last digit.

ΔT = ½ × 0.1 °C
ΔT = ± 0.05 °C
Step 03 — Why?

The truncation rule.

// The device rounded to 25.4 °C.
// True value lies in [25.35, 25.45) °C.
// Worst-case error from rounding
// is half of the rounding step.
Reported value
T = 25.4 ± 0.05 °C
